# Matriz de migración de la documentación del backend

Trazabilidad de la migración de los nueve documentos que quedaban en `docs/` de `nataliachala1/smarthome-backend` después del PR #18. Mientras existan los originales en el backend, los destinos son copias. Commit de referencia: `dev` `fea02540ae12ed7501ae2b75f6216ab00411796a`.

## Criterios

- **Vigencia:** `vigente verificado`, `implementación documentada`, `histórico` o `pendiente de confirmar`. Ningún documento se declara vigente verificado: no se ejecutaron pruebas ni se acreditó aprobación.
- **Contraste con `dev`:** se buscaron en el código los identificadores citados entre comillas invertidas (variables, eventos, rutas, clases) y se reconstruyeron las rutas HTTP desde los decoradores de los controladores. Las columnas SQL citadas se buscaron en `smarthome-database` `dev`.
- **Conservación:** se comprobó que todas las líneas del original aparecen en el destino, en el mismo orden, salvo los destinos de enlaces relativos.
- **Revisión:** cada fila queda pendiente hasta que la persona responsable registre `APROBADO PARA RETIRO` o `BLOQUEADO` con motivo.
