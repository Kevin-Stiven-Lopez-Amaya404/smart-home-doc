# Copias históricas sanitizadas

Las copias de esta carpeta conservan el texto de origen pero reemplazan coincidencias conocidas de credenciales de demostración. Están guardadas como `.txt` porque los Markdown históricos no siguen la estructura, metadatos y validaciones actuales del repositorio central.

Consultar el [índice y el manifiesto](../README.md). Los hashes listados corresponden al **blob original**, no a la copia redigida. No ejecutar ejemplos antiguos de autenticación, pairing o despliegue sin revisar primero el código vigente.
