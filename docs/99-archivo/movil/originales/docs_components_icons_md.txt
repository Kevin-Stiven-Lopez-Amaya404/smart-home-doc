# Componentes - icons

## GoogleIcon
- Ruta: `components/icons/GoogleIcon.tsx`
- Descripción: Icono SVG de Google usado en el botón de login social.
- Props:
  - `size?: number` — tamaño en píxeles del icono (ancho y alto, default `24`).
- Ejemplo:
```
<GoogleIcon size={30} />
```

## CheckIcon
- Ruta: `components/icons/CheckIcon.tsx`
- Descripción: Icono SVG reutilizable de confirmación.
- Props:
  - `color?: string` — color del trazo (default `#FFFFFF`).
  - `size?: number` — tamaño en píxeles (default `14`).
- Ejemplo:
```
<CheckIcon color="#34A853" size={18} />
```
